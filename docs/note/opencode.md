# OpenCode

## install

### npm

npm 新版默认拦截安装脚本, 需显式放行.

#### 局部安装

```sh
npm install @opencode/cli
npm install-scripts approve @opencode/cli
npm rebuild @opencode/cli
```

## commend

### session

`opencode session list`

### update

```shell
opencode upgrade
```

`--method <way>`: 指定安装方式.
