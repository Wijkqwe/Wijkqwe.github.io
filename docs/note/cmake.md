# CMake

## 关键字

### 库类型

用于 `add_library()` 命令中, 指定库类型的 `<type>` 参数.

- `STATIC`：静态库. 在链接其他目标时使用的目标文件归档文件.
- `SHARED`：共享库. 可以被其他目标链接并在运行时加载的动态库.
- `MODULE`：模块库. 一种插件, 不能被其他目标直接链接, 但可以在运行时通过 dlopen 等方式动态加载.
- `OBJECT`：对象库. 编译源文件, 但不归档或链接成库, 而是生成一组目标文件（.o或.obj）, 供其他目标通过 $<TARGET_OBJECTS> 表达式引用.
- `INTERFACE`：接口库. 它自身不编译源文件, 也不在磁盘上生成库文件, 通常用于表示一个仅头文件（header-only）库, 或为依赖它的目标传递编译选项、宏定义等使用要求.
- `IMPORTED`：导入库. 用于描述一个位于当前项目外部的、已经存在的库目标. 它本身不生成构建规则, 只为方便地在项目中引用外部库文件.

## 生成器表达式

语法 `$<...>`, 它的值会在构建系统生成时或实际编译时才被计算.

### 分类

根据文档中的标准区分.

```cmake
$<qwe:asd>
```

- 条件表达式: qwe 是能得出布尔值的表达式, asd 是条件为真时的返回值.
- 信息表达式: qwe 是一个查询命令, asd 是参数.

### 内置表达式

- COMPILE_LANGUAGE: CMake 3.0 版本之后被引入. 通过 `$<COMPILE_LANGUAGE:lang1,lang2,...>` 作为**信息表达式**使用, 返回一个布尔值.
