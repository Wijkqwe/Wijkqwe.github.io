# Java

## 配置

### Windows

1. 下载java
0. 配置环境变量
	1. 新建`JAVA_HOME`变量
		- 变量名`JAVA_HOME`
		- 路径`...\Java\jdk-%d`
	0. 修改`Path`变量
		- 新建`%JAVA_HOME%\bin`
	0. 连续“确定”保存
0. 验证

#### Maven

1. 下载maven
0. 配置环境变量
	1. 新建`MAVEN_HOME`变量
		- 变量名`MAVEN_HOME`
		- 路径`...\Maven\apache-maven-...`
	0. 修改`Path`变量
		- 新建`%MAVEN_HOME%\bin`
	0. 连续“确定”保存
0. 验证`mvn -v`
