# Assembly

## x86

分为 2 种语法: 

- Intel
- AT&T: 主要用于 GNU/Linux, LLVM.

### AT&T

```
指令 源操作数 目的操作数
```

#### 指令后缀

指令后的单字母后缀，用于表示操作数数据宽度 / 数据类型.

| 后缀 | 英文 | 宽度 | 位数 |
|--|--|--|--|
| b | byte | 1 字节 | 8 位 |
| w | word | 2 字节 | 16 位 |
| l | long | 4 字节 | 32 位 |
| q | quad | 8 字节 | 64 位 |

#### 寄存器

寄存器名称前缀 `%`.

##### 通用寄存器

- 累加器
    - 64: `%rax`
- 基址寄存器
    - 64: `%rbx`
- 计数器
    - 64: `%rcx`
- 数据寄存器
    - 64: `%rdx`
- 源变址
    - 64: `%rsi`
- 目的变址
    - 64: `%rdi`
- 栈帧指针寄存器
    - 64: `%rbp`
- 栈指针寄存器: 始终指向栈顶.
    - 64: `%rsp`
- `%r8`-`%r15`
