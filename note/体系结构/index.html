    定量分析技术

    四个定量原理

    • 加快经常性事件

    • Amdahl定律

      S_n = 1 / ((1 - F_e) + F_e / S_e)

      加速比定义：S_n = 新速度/旧速度 = 旧时间/新时间 = T_0 / T_n

      改进后时间定义：T_n = T_0(1 - F_e + F_e / S_e)

    • CPU性能公式 CPU时间 = IC(指令数) * CPI(平均指令周期数) * 时钟周期时间(时钟频率的倒数)

      总时钟周期数 = CPI/IC

      CPI = 指令执行时间 + 每条指令平均访存次数 * 不命中率 * 不命中开销

    流水线

    概念

    流水线技术

    • 把一个重复的过程分解为若干个子过程，每个子过程由专门的功能部件来实现
    • 把多个处理过程在时间上错开，依次通过各功能段，这样，每个子过程就可以与其他的子过程并行进行

    形成条件

    多个密集且相同或类似的任务的场景

    技术特点

    性能指标

    吞吐率

    定义

    在单位时间内流水线所完成的任务数量或输出结果的数量

    TP = n(任务数) / T_k(处理n个任务所需时间)

    各段时间相等

    实际吞吐率

    TP = n / ((k + n - 1)\deltaΔ t)

    最大吞吐率

    TP_max = lim_{n \to \infty} n / ((k + n - 1)\delta t) = 1 / (\delta t)

    TP = (n / (k + n - 1))TP_max

    当n趋近于k时，TP趋近于TP_max

    各段时间不全相等

    T_k＝∑Δt_i＋(n - 1)max(Δt_i)

    实际吞吐率

    TP = n / (∑Δt_i＋(n - 1)max(Δt_i))

    最大吞吐率

    TP_max = 1 / max(Δt_i)

    解决流水线瓶颈的方法

    • 细分瓶颈段

    加速比

    完成同样任务，使用流水线与不使用流水线时间比 S = T(不使用) / T(使用)

    各段时间均等

    实际加速比

    S = nk / (k + n - 1)

    最大加速比

    S = k

    各段时间不等

    效率

    流水线中的设备实际使用时间与整个运行时间的比值

    各段时间均等

    各段效率相等 e = nΔt / T_k = n / (k + n - 1)

    整条流水线效率 E = ke / k = n / (k + n - 1)

    E = (设备实际使用时间) / (段数 * 流水线通过的时间)

    最高效率 E_max = 1

    效率与吞吐率成正比 E=TP·△t

    流水线的效率是流水线的实际加速比S与它 的最大加速比k的比值

    设由M1，M2组成的两级存储层次，N_1访问M1的次数，N_2访问M2的次数

    H = N_1 / (N_1 + N_2)

    F = 1 - H
