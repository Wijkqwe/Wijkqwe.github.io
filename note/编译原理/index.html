    预测分析

    对文法G[S]

    S入栈，待分析句子入队，栈队皆为#则匹配

    |栈|队|操作|

    FIRST

    对非终结符A，观察产生式A -> a 若a第一个符号是终结符，则将其加入FIRST(A) 若a第一个符号非终结符B，则将FIRST(B)中除空串外加入FIRST(A)；若B可推导出空串，则继续将空串加入FIRST(A)，并继续判断B后一个字符

    FOLLOW

    对非终结符A，观察产生式B -> *A* 若A为开始符号，将#加入FOLLOW(A) 若A后*第一个字符是终结符a，则将a加入FOLLOW(A) 若A后*第一个字符是非终结符，则将FIRST(a)加入FOLLOW(A) 若A后*为空串或可推导为空串，则将FOLLOW(B)加入FOLLOW(A)

    SELECT

    对产生式A -> * 若*不为空且不可空，则SELECT(A -> *) = FIRST(*) 若*不为空且可空，则SELECT(A -> *) = FIRST(*) 并 FOLLOW(A) 若*为空，则SELECT(A -> *) = FOLLOW(A)

    FIRSTVT

    对非终结符A，观察A -> * 将*中最左终结符加入FIRSTVT(A) 若*第一个字符是非终结符B，则将FIRSTVT(B)加入FIRSTVT(A)

    LASTVT

    优先关系表

    观察产生式右部 若有aQb或ab，则a = b 若有aQ，则a < FIRSTVT(Q)，a所在行< 若有Qb，则LASTVT(Q) < b，b所在列>

    算符优先文法

    任意产生式的右部都不含两个相继（并列）的非终结符 任意终结符一种优先关系

    正规文法转有穷自动机

    设给定一个左线性正规文法 G = (V N , V T , P , S ),则相应的有穷自动机 M = ( Q , Σ , f , q 0 , Z ) (1 )将 V N 中的每一个非终结符视作 M 中的一个状态,并增加一个初始状态 q 0 且q 0 ∉ V N ,令 Q = V N ∪ { q 0 },并将文法 G 的开始符号 S 看成终结状态,即 Z = { S }, Σ = V T 。

    (2 )对 G 中每一形如 A → Ba 的产生式( A , B ∈ V N , a ∈ V T ∪ { ε }),令 f ( B , a ) = A 。

    (3 )对 G 中每一形如 A → a 的产生式( A ∈ V N , a ∈ V T ∪ { ε }),令 f ( q 0 , a ) = A 。

    右线性正规文法 对 A → aB, 令 f ( A , a ) = B 对 A → a, 令 f ( A , a ) = Z
